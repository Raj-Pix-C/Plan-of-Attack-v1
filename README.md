# Plan-of-Attack version 1.0
---
*Browser Edition using HTML, CSS & JS*

# Design
---
* A six column grid: Checkbox, Start, End, Duration, Agenda & Comment
* At the beginning of each Start time an alert is executed
* Browser Localstorage is used for saving the rows
* If no data is found during startup input popup is loaded
* Else index.html loads the rows
* Buttons are present for editing rows and reseting list
* Checkbox data is collected and stored in Localstorage
* Daily, weekly, monthly assessment available
